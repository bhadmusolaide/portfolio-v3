# Olaide Bhadmus — AI Engineer Portfolio

Portfolio site and resume variants for Olaide Bhadmus, an AI Engineer building production LLM applications.

## Structure

- `portfolio-site/` — Next.js portfolio site with case studies
- `resumes/` — Master resume and variant formats
- `evidence-register/` — Evidence linking claims to sources

## Tech Stack

- Next.js, React, TypeScript
- Tailwind CSS
- Deployed via Netlify

## Quick Start

```bash
cd portfolio-site
npm install
npm run dev
```
